# Act 1. The problem

## Search

### Typing beats navigating

I cut the app down to search only — you type a word, results appear as you type, and one tap adds the symbol to the top line. The seamless search covers fifty eight thousand symbols and every one of them can be found in a moment by typing or speaking into the app. Parents told me the color of each tile mattered less than knowing where to find it, so I changed the layout again and again until it worked.
